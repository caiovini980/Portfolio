# Portfolio

Personal portfolio website for **Caio Aguiar**, a software engineer for games. Showcases game-dev projects (shipped titles and side projects) with a light/dark theme, animated transitions, and per-project detail pages.

**Live site:** https://caiovini980.github.io

## Built with

- [React](https://react.dev/) + [React Router](https://reactrouter.com/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [gh-pages](https://github.com/tschaub/gh-pages) for deployment

## Getting started

### Prerequisites

- [Node.js](https://nodejs.org/) (with npm)

### Installation

```bash
git clone https://github.com/caiovini980/Portfolio.git
cd Portfolio
npm install
```

## Usage

```bash
npm run dev              # start the dev server with hot reload
npm run build             # production build to dist/
npm run preview           # preview the production build locally
npm run lint               # run eslint
```

Site content (projects, side projects) lives in plain JS data files under `src/data/` — edit those to add or update portfolio entries.

## Deployment

The site deploys to GitHub Pages via `gh-pages`:

```bash
npm run build-and-deploy   # builds, then publishes dist/ to the gh-pages branch
```

## Project status

Actively maintained but a perpetual work in progress — some sections (project/side-project detail pages) are still placeholders.
